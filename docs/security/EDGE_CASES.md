# Edge cases that tests must cover

Each component's tests must cover every edge case listed for it. A test names the ID in a comment (for example `// EC-C09`). `test-auditor` checks that each ID has a test, and that the test asserts the right outcome, not just that something happened. Add new IDs when audits or bugs reveal new cases; never renumber.
